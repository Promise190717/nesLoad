## 分页 / 机种 tab / 语种 tab 从 query 搬进路径（治「点一下整页刷新」）

- 起因：用户报「列表页的分页和 tab 点一下整页刷新」。根因就是 `CatalogLink` 那套 —— `?page=` / `?console=` / `?lang=` 被 `middleware` 的 `catalogRewrite` 改写成 `/catalog/...` 影子路由，客户端软导航 flight 对不上，只能退回整页跳转。
- 解法：维度进路径，真路由 ⇒ 软导航恢复。`CatalogLink.tsx` 删除，相关链接全换 `next/link`。
  - `/games[/console/<type>][/page/N]`、`/consoles/<id>[/lang/<code>][/page/N]`、`/developers[/page/N]`、`/developers/<id>[/page/N]`
  - 搜索单独动态路由：`/games/search?q=&console=&page=`、`/consoles/<id>/search?q=&lang=&page=`（关键词不进路径；脚本注释里写了理由：用户输入含斜杠/超长串）
- 10 个薄壳（`app/[locale]/…/page/[n]/page.tsx` 等）只把**路径段翻译成 `searchParams`**，页面组件解析/收敛/canonical 逻辑一行没改。
- `lib/pager.ts` 的 `pageHref` 改成 `${base}/page/N`；`gamesHref` / `consoleHref` 双分支（有搜索词走 search 路由，否则路径段）。
- `catalogRewrite` **保留**：只兜旧外链（`/games?page=2` 仍能打开），文件头重写成「这是兼容层，别再加新维度」。
- 搜索表单：action 变成 `actionPath + '/search'`，新增 `clearHref` prop（清除落回浏览态路径）。
- README / sitemap 注释同步；`prefetch={false}` 加在十几颗一排的 tab 上（防止每次开页预渲染十几条路由）。
- tsc 通过；eslint 只剩既有那批（PlayScene/ConsoleScene 等 react-hooks 报错，与本次无关）。
