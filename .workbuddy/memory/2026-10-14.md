## 用户拿「别人家的 19 个机种」来问我们哪些能做（可行性核定）

别人家清单：GBA 421 / NDS 372 / PS 361 / SFC 247 / FC 223 / 街机 192 / N64 93 / MD 76 /
GBC 37 / GB 32 / 土星 15 / Game Gear 13 / Master System 9 / WonderSwan 5 / NeoGeo掌机 4 /
32X 4 / Sega CD 4 / Jaguar 1 / PC Engine CD 1。

对着 `retroarch-emscripten-build@v1.22.2` 的 90 个核心 + Nostalgist 的 `coreInfoMap` 逐个核过：

- **做不了 4 项**（那个构建里根本没编，已核验计数全 0）：NDS（无 desmume/melonds）、N64（无 mupen64plus）、
  土星（无 saturn/yabause/kronos）、Jaguar（无 virtualjaguar）。
- **已经有 4 项**：GBA / SFC / FC / 街机。
- **能直接做 8 项**：MD / Game Gear / Master System（一个 `genesis_plus_gx` 全覆盖）、32X（`picodrive`）、
  GB / GBC（现成 `mgba` 就兼容，零新核心文件）、WonderSwan（`mednafen_wswan`）、NeoGeo 掌机（`mednafen_ngp`）。
- **能做但要额外条件 3 项**：PS1（`pcsx_rearmed` 有，但要用户自备 BIOS + wasm 跑 3D 吃力）、
  Sega CD（要 3 个 BIOS 文件）、PC Engine CD（要 syscard BIOS）—— 这三项还都是**多文件光盘镜像**（cue+bin），
  和现在「单文件 / 单 zip」的载入流程不合。
- 存档相关：`genesis_plus_gx`/`picodrive`/`gambatte`/`mednafen_wswan`/`mednafen_ngp`/`pcsx_rearmed`
  在 Nostalgist 里都标了 `savestate: true`（我们的存档钮能跟着用）；`gearboy`/`gearsystem`/
  `gearcoleco`/`mednafen_lynx`/`mednafen_vb` **没标**，用它们得自己兜存档。
- 两个跨机种的机制性缺口（加之前要先解决）：① `lib/bios.ts` 现在**全项目只存一份 BIOS**、id 写死
  `neogeo`（文件里注释自己就写了「将来支持别的机种再改成按机种分 key」），引擎侧 `bios?: File | null`
  也只能收一个；而 Nostalgist 的 `bios` 本身**支持数组**（`{fileName, fileContent}[]`，多文件 BIOS 可行）。
  ② 光盘机种要多文件 ROM。③ 加机种要顺带改 `home.hero.lead` 那句机种列举（还有 `home.faq.a6`/`netplay.open`
  那三处对齐过的措辞）。本次只做核定，未动代码。

### 机图（8 张，走了弯路）

- ⚠️ **不能用 `ImageGen` 并行出图**：`output_dir` 参数不生效（四张全落进同一个目录），
  文件名只有秒级时间戳 ⇒ 同秒的互相覆盖（四张只活下来两张）。
- 改用 **`miora_text_to_image`**：文件名带毫秒 + 哈希，天然不撞，可以并行。
  但它和 ImageGen **都会在右下角烧「AI生成 / WORKBUDDY」水印**（平台加的，两条通道都有）。
- 旧的四张（NES/SFC/GBA/街机）没有水印，所以**统一按行取背景色把水印填掉**
  （水印 bbox ≈ `(900,960)-(1013,1013)`，背景是平色，填完无接缝）——
  脚本用本地 venv 里的 Pillow（`~/.workbuddy/binaries/python/envs/default`）。
  落地图在 `.workbuddy-ai/tmp/console-images/<type>.png`（1024×1024）。
- 辨认「哪张图是哪个机种」的办法：**拼一张带编号的联络表看一次**，别一张张看。

### 缓存（两处结构性改动）

- ⚠️ **bug 根因**：`unstable_cache` 条目落在 `.next/cache`，**进程重启照样命中**。
  加机种后 `countGamesByConsoleCached` 仍返回加机种前那份**只有四个键**的旧对象，
  `/consoles` 页取 `counts['gb']` 得到 `undefined` ⇒ 界面印出「undefined 款游戏」。
- 修复两件：① `countGamesByConsoleCached` 改成**函数**，读完缓存后按 `CONSOLE_TYPES` 补 0，
  对外永远是完整记录；② 键升版本 —— `games:console-counts` → `v2`、`consoles:list` → `v2`
  （**改完库内容不换键，前台要等一个 TTL 才看得到**，这是本项目的既定手法）。
- 新增 **`lib/server/cache.ts`**：`cached()` 薄封装，**开发模式直接透传、不缓存**，
  线上参数原样交给 `unstable_cache`。8 处 `unstable_cache` 全部改走它。
- TTL：首页 / 机种库 / 开发商那三个 **86400 → 43200（12 小时）**；
  `/games` 列表页仍 **1800（30 分钟）** —— 那是货架页，要尽快看到新游戏。
