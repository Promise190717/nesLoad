  `showHeader={false}`（名字/资料在右列，顶上不再来个大标题；h1 由 PlayScene 出 sr-only 的）、
  `fill`（外层变 flex-col + `min-h-[calc(100vh-3rem)] sm:min-h-[calc(100vh-6rem)]`，children 套 `flex-1`
  ⇒ **页脚压到视口最底**、内容吃满剩余高度）。于是 `.wall` 背景、`TopBar`、返回、页脚全部和内容页一致。
- **PlayScene 根改成 fragment + 一个 `flex-1 ... lg:items-stretch` 的行**（`<main>` 交给外壳）。
  左栏 `section` 用 `items-center justify-center` ⇒ **屏幕在剩余高度里上下居中**；屏宽上限
  `min(100%, calc((100vh - 320px)*4/3))`（320px = 外壳 + 外框 + 页边距的估计值）。
- **房间选择搬进屏幕叠层**：单人/创建/加入 + 加入码 + 链路 + 画质 + 主按钮都在里面；进房换成
  房间码（大字）+ 复制/分享 + 状态 + 离开；载入中 = 阶段 + 进度条 + 取消。
- **右列**：顶上封面（`pixel-edge` + 3:4 `object-cover`）+ 名字 / 机种·年份 / 开发商；
  中间 `ul.divide-y` 的六行操作表（暂停·重载·弹出·音量·显示·全屏，每行「说明在左、控件在右」）；
  底下 `pixel-edge` 的「编辑」钮（tooltip = `keybind.open`）；最下 `play.hint`。
