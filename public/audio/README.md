# public/audio

地板上那台 MP4（点一下播放 / 暂停）的音源放在这里。

- **文件名必须是 `i-miss-you.mp3`** —— `components/ConsoleScene.tsx` 里那个
  `<audio>` 的 `src` 写死成 `/audio/i-miss-you.mp3`。
- **仓库里不带这个文件。** 那首歌是有版权的录音制品，得你自己准备一份、
  按上面这个名字放进来（换别的歌也行，改名即可 —— 但那要同步改 `src`）。
- **文件不在会怎样**：不会哑掉 —— 会**自动退到现场摇的 8-bit 小段**
  （`lib/chiptune.ts`，运行时手搓一段 WAV，1.3–3.8 秒不等）。而且**每点一次都现摇一段新的**
  —— 主音、调式、速度、音色、旋律走向、长度全在点下去的那一刻随机。
  那一段**放一遍就停**，不像真歌那样循环（屏幕上的歌词滚动也跟着停）。
  浏览器 console 里会有一行
  `[mp4] i-miss-you.mp3 放不出来，改用现场合成的 8-bit 小段…`。
  不会弹窗报错，也不会假装在播。
- 兜底**只退一次**：一旦退过去，这一整个页面生命周期里就一直用合成的，不再回头试 mp3。
  刷新页面才会重新先试文件。

> ⚠️ 兜底那段旋律是**原创**的（只在五声音阶里随机游走，所以怎么摇都不会跑调），
> 和「I MISS YOU」没有任何关系。**别把原曲的调子抄进 `lib/chiptune.ts`** ——
> 那是版权问题，不是风格问题。

这个 README 会跟着 `public/` 一起被静态托管（`/audio/README.md`），无所谓 ——
它只是为了让这个空目录能进 git，顺便说明放什么。
